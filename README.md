# My Portfolio Website

### Personal Portfolio with AI Assistant

## Project Overview

This project is a personal portfolio website developed to showcase my technical skills, programming projects, and learning journey in Computer Science Engineering. It includes an AI-powered assistant and interactive features to provide visitors with a better browsing experience.

## Objectives

- To create a professional online portfolio.
- To showcase programming projects and technical skills.
- To integrate an AI assistant into a website.
- To implement interactive web features.
- To learn website deployment using GitHub and Vercel.

## Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and layout
- **JavaScript** – Interactive functionality
- **OpenAI API** – AI assistant integration
- **Weather API** – Weather information
- **GitHub** – Source code management
- **Vercel** – Website deployment

## Key Features

- Personal introduction and skills section
- Project showcase
- AI-powered chatbot
- City-based weather forecast
- User-friendly website interface
- Live website deployment
